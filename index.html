Task 7: e-learning platform

Cohort

The completion issue of online courses is not about discovering but about stopping. Individuals sign up for courses but leave them unfinished. Thus, the two real issues of the brief, the need to keep students involved and offering them some system of tracking progress, become one solution.

Enrolment asks for a pace, not just a payment

The enrolment page requests the user to input the number of hours they are able to dedicate to learning. If the user inputs the number 90 minutes, then the app registers that the course will end on November 12, thereby completing the first step of turning an abstract idea into something more concrete. From that moment on, all the following screens will have something to measure against. Each lesson is based on the selected number of hours

Progress is what you can do, not what you watched

The program measures how long the user has managed to attend all the classes by showing a percentage bar. Each course consists of a few practical skills, and a skill is considered to be passed only when the user has shown the required results on a final exam. Four out of the seven skills can be said to be “presentable”, meaning that the candidate can name them in an interview. However, a 62 percent success only means that there are still things to learn.

Home is resume first, sized to the time you have

The top of the home screen is the lesson you left off with, along with information about being either on pace or falling behind. Below is something no one ever asks learners: How much time do you have at this moment? Ten minutes means a very different set of lessons from forty-five. Most drops happen as soon as a learner opens the app and realizes that they do not know what lesson is appropriate.

Focus mode

The lesson player is the only screen that uses warm colors instead of bright paper, with no tab bar and just the lesson on it with a progress bar. Long reading on dark backgrounds can be exhausting for the user, and changing the color scheme shows that the user is in a new mode, in which they no longer browse.

User flow

Home→Continue→Lesson→Check→Skill marked
Browse→Course→Set pace→Enrolled→First lesson
Home→Time I have→Lesson that fits
Progress→Skills→Course→Next lesson

The rule: green is both the action colour and the on pace colour, which is deliberate, since the action always is the thing that gets you back on pace. Amber appears only when you are behind. Warm paper appears only inside a lesson, nowhere else, so the mode switch is unmistakable.

Type

  • Plus Jakarta Sans 400 to 800 for the whole interface.
  • Literata for lesson text only. It was drawn for long reading on screens, and reserving it for the reading view means the serif itself signals you are learning rather than browsing.
  • Scale: 27 for titles, 21, 18, 17 for lesson body, 15, 14.5, 12.5, 11.5.
